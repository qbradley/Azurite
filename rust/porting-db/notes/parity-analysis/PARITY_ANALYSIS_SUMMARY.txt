ISSUE #1: Create Container ETag Differs
────────────────────────────────────────
Status:         ❌ FAIL
Test Output:    TS=['"0x2617CE0B8607660"'] Rust=['"0x1BC2B675F878C4D"']

Root Cause:     ETag randomness source mismatch
   • TS uses:    Math.random() × timestamp
   • Rust uses:  subsec_nanos() × timestamp (wrong distribution)

TS Code:        /home/azureuser/Azurite/src/common/utils/utils.ts:55-66
   function newEtag(): string {
     return '"0x' + (new Date().getTime() * Math.round(Math.random() * 30000 + 70000))
       .toString(16).toUpperCase() + '"';
   }

Rust Code:      /home/azureuser/Azurite/rust/crates/azurite-common/src/utils/utils.rs:84-92
   fn newEtag() -> String {
       let now = Utc::now().timestamp_millis() as u64;
       let random = SystemTime::now().duration_since(UNIX_EPOCH).unwrap().subsec_nanos() as u64;
       let multiplier = random % 30001 + 70000;  // WRONG: subsec_nanos != Math.random()
       format!("\"0x{:X}\"", now.saturating_mul(multiplier))
   }

Minimal Fix:    Replace subsec_nanos() with proper RNG (use `rand` crate with Math.random() behavior)
Affected Ops:   Container creation
Impact:         All subsequent operations on container inherit mismatched ETag

                Difference: 370 microseconds

Root Cause:     Different high-precision timestamp implementations
                TS uses process.hrtime()[1] sampled at request time
                Rust uses SystemTime::now().subsec_nanos() sampled in function call
                These are sampled at different times → different nanosecond values

TS Code:        /home/azureuser/Azurite/src/common/utils/utils.ts:175-195
   export function truncatedISO8061Date(date: Date, ..., hrtimePrecision: boolean = false): string {
     const dateString = date.toISOString();
     if (hrtimePrecision) {
       return (
         dateString.substring(0, dateString.length - 1) +
         process.hrtime()[1].toString().padStart(4, "0").slice(0, 4) +  // Samples at call time
         "Z"
       );
     }
     ...
   }

   private createPersistedEntity(...) {
     const modTime = truncatedISO8061Date(context.startTime!, true, true);  // hrtimePrecision=true
     const eTag = newTableEntityEtag(modTime);
   }

Rust Code:      /home/azureuser/Azurite/rust/crates/azurite-common/src/utils/utils.rs:108-130
   pub fn truncatedISO8061Date(date: DateTime<Utc>, ..., hrtimePrecision: bool) -> String {
     let dateString = date.to_rfc3339_opts(SecondsFormat::Millis, true);
     if hrtimePrecision {
       let hrtime = SystemTime::now()  // ← Samples NOW (not at context creation time!)

       let padded = format!("{:0>4}", hrtime);
       return format!("{}{}Z", &dateString[..dateString.len() - 1], &padded[..4]);
     }
     ...
   }

   }
