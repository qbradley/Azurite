PROBLEM SUMMARY (1-paragraph)
═════════════════════════════

The Rust CORS implementation has three critical bugs: (1) middleware execution
order is wrong - the serializer runs before the OPTIONS handler, so CORS headers
can't be added to the response; (2) the blockErrorRequest logic bug at lines
235-237 drops error state, breaking the error handling chain; and (3) error
responses for failed CORS preflight checks don't set the 403 status code. These
are simple fixes (~20 lines total) that don't require rewriting the CORS logic,
which is actually correct. TypeScript works because middleware ordering is
correct and error handling is proper.
